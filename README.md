# Online Library - backend integrado

Entrega DSY1104: administración de Vania, tienda/pedidos de Vale y contenido de Ale.

Usar **docker-compose.entrega.yml**. Lee [ENTREGA.md](ENTREGA.md) para instalación limpia, variables, contratos, seguridad, pruebas y límites. Backend de entrega: `Vania-Bustos-Fuentealba/proyecto-fullstack2`; rama de integración: `feature/react-tienda`.

El despliegue usa Gateway, Auth, User, Book/Pedidos, Content y MySQL. Los microservicios históricos se conservan; no forman parte del recorrido verificado. Los créditos y arquitectura originales están en [README-HISTORICO.md](README-HISTORICO.md).
